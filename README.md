
# Credit Risk: Probability of Default Modelling & Calibration

## Project Overview
This project investigates the prediction and calibration of
credit card default probabilities using statistical and
machine learning models.

## Objectives
- Explore credit risk characteristics in borrower data
- Estimate default probabilities using logistic regression
- Compare performance with a tree-based model
- Evaluate discrimination using ROC-AUC
- Assess probability calibration using Brier scores
  and reliability diagrams
- Group borrowers into interpretable risk bands

## Dataset
UCI Default of Credit Card Clients dataset
Source: https://archive.ics.uci.edu/dataset/350/

## Tools
Python, pandas, NumPy, scikit-learn, matplotlib

In progress — data exploration and model development.
